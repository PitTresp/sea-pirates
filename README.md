# SEA Pirates

**Software Engineering Academy**

SEA Pirates ist ein langfristiges Lern- und Entwicklungsprojekt zum praktischen
Erlernen von Software Engineering.

Im Mittelpunkt steht nicht das Auswendiglernen von Syntax oder Definitionen,
sondern das Verständnis dafür, warum Software auf bestimmte Weise entworfen,
implementiert, getestet und weiterentwickelt wird.

## Mission

SEA Pirates verbindet drei Ziele:

1. Software Engineering verstehen und praktisch anwenden.
2. C# und .NET anhand einer kontinuierlich wachsenden Anwendung erlernen.
3. Systematische Vorbereitung auf die AP2 der Ausbildung zum
   Fachinformatiker für Anwendungsentwicklung.

Der erste konkrete Prüfungsmeilenstein ist die AP2 am 25.11.2026.
Das Projekt ist jedoch ausdrücklich über diesen Termin hinaus angelegt.

## Lernprojekt: SEA Academy

Als durchgängiges Praxisprojekt entsteht schrittweise die **SEA Academy**,
ein kleines Wissens- und Lernmanagementsystem.

Die Anwendung wächst gemeinsam mit den erworbenen Fähigkeiten.

Neue Anforderungen werden bewusst genutzt, um Themen wie Objektorientierung,
Datenhaltung, Architektur, Tests, Schnittstellen, Sicherheit und
professionelle Entwicklungsprozesse praktisch zu erarbeiten.

## Lernprinzip

> Verstehen vor Implementieren.

Code wird nicht allein deshalb als gut betrachtet, weil er funktioniert.
Entscheidungen sollen verstanden, begründet und bei neuen Erkenntnissen
hinterfragt werden können.

Fehler sind ausdrücklich Teil des Lernprozesses.

## Arbeitsweise

SEA Pirates kombiniert:

- Engineering-Dialoge und freie Lösungsfindung
- schrittweise Implementierung
- Code Reading
- gezielte Theorie
- Refactoring und Fehleranalyse
- AP2-nahe Aufgaben
- regelmäßige Bearbeitung alter Prüfungen
- Reflexion durch Captain's Reviews

Die Dokumentation folgt einem bewusst vereinfachten Engineering-Standard.
Sie soll Orientierung und Übergabefähigkeit schaffen, ohne zum Selbstzweck
zu werden.
