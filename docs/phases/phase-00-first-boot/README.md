# Phase 0 – The First Boot

## Zweck

Phase 0 schafft eine kontrollierte Ausgangsbasis für SEA Pirates.

Es wird noch keine fachliche Funktion der SEA Academy implementiert.

## Ziele

- Entwicklungsumgebung verifizieren
- GitHub-Repository herstellen
- lokale und entfernte Versionsverwaltung verbinden
- minimale Dokumentationsstruktur etablieren
- Lernprinzip und Roadmap festhalten
- Ausgangspunkt für Phase 1 herstellen

## Nicht-Ziele

- Produktarchitektur festlegen
- Frameworks auswählen
- Datenbank auswählen
- Benutzeroberfläche entwickeln
- fachliche Features implementieren
- Design Patterns vorsorglich einführen

## Definition of Done

Phase 0 ist abgeschlossen, wenn:

- Entwicklungsumgebung funktionsfähig ist
- Repository lokal und remote funktioniert
- Foundation-Dokumentation committed ist
- ein minimales C#-Projekt erstellt und ausführbar ist
- der Repository-Stand sauber ist
- ein Captain's Review durchgeführt wurde
- der Einstiegspunkt für Phase 1 dokumentiert ist
